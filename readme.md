## Логика решения

### 1. Очистка данных

Ключевой риск - несогласованные и аномальные высотные атрибуты в обоих источниках. Пятиэтапная очистка:

- **Удаление шумовых объектов** (дубликаты, малая площадь, малые здания) - удалено **42 818** объектов
- **Пространственная валидация** (ошибки WKT, объекты вне СПб) - проверены все объекты
- **Очистка атрибутов** (валидация этажности и высоты, приведение категорий к единому формату) - исправлен **991** атрибут
- **Consistency check** (логическая проверка: `height ≈ stairs × avg_floor_height`) - помечено **384** объекта

Итог: **A - 80.4% retention**, **B - 94.2% retention**

### 2. Пространственное сопоставление (matching)

Для каждой пары полигонов с пересечением вычисляется **MATCH SCORE**:

```
MATCH SCORE = 0.45 × IoU + 0.25 × MAX_COVER + 0.20 × SIZE_RATIO + 0.10 × CENTROID_DIST
```

Где:
- `IoU` = S_пересечения / S_объединения
- `MAX_COVER` = max(S_пересечения/S_A, S_пересечения/S_B)
- `SIZE_RATIO` = min(S_A, S_B) / max(S_A, S_B)
- `CENTROID_DIST` = расстояние между центрами / √(min(S_A, S_B) / π)

Каждый полигон сохраняет только **2 лучшие связи** - затем строится граф и объединяются пары с наибольшей силой.

Выявлено 5 типов пространственного соответствия:

| Тип | Доля | Решение |
|---|---|---|
| Хорошее совпадение | 55.7% | Объединяем атрибуты |
| Параллельный сдвиг | 23.2% | Корректирующий сдвиг слоёв |
| Один в другом | 14.3% | Берём больший контур как основной |
| Неверный адрес | 5.2% | Добавляем как отдельные объекты |
| Пограничные случаи | 1.6% | Исключаем из обучения и автослияния |

Приоритизация источника через **SOURCE_SCORE**:

```
SOURCE_SCORE = 35% detail + 30% support + 20% agreement + 10% frag_penalty + 5% area_penalty
```

Если `score_A > score_B + margin` - берём геометрию из A.

### 3. Feature Engineering

Сконструировано **47 признаков** → после отбора осталось **35**:

| Группа | Кол-во | Ключевые признаки |
|---|---|---|
| Геометрические | 10 | `area_m2`, `log_area`, `npi`, `bbox_ratio`, `convexity`, `geom_parts` |
| Пространственные | 15 | `mean_height_100m` ★, `kde_50m..200m`, `p75_height_100m`, `mean_height_by_district` |
| Категориальные | 10 | `stairs_clean`, `avg_floor_height`, `purpose_B_enc`, `category_A_enc`, `is_residential` |

> ★ Средняя высота соседей в 100 м - самый важный признак модели.
> Индекс Морана **0.63** подтверждает высотную кластеризацию. Корреляция Пирсона `mean_height_6nn` с целевой переменной: **0.81**.

Категориальные признаки дают **59.8% влияния** на целевую переменную, пространственные - 31.2%, геометрические - 8.8%.

Отбор признаков - диагностика квазиутечки (`|r| > 0.95`), фильтрация коллинеарных пар, Bootstrap-CI для выбора оптимального K.

### 4. Обучение моделей

Целевая переменная: `log(высота + 1)` → обратное преобразование на инференсе: `exp(pred) − 1`.

> Обычный random split завышает метрики: соседние здания «подсказывают» ответ через пространственную автокорреляцию. Использована **пространственная CV**.

**Random Forest** (Farella et al. 2021):
- `n_estimators=400`, `max_features=sqrt`, `min_samples_leaf=5`, `oob_score=True`
- Валидация: KMeans → 5 территориальных зон, каждая по очереди тестовая
- Аугментация зданий >50 м: ×3 копии с шумом ±10% в геометрии

**CatBoost**:
- `iterations=2000`, `learning_rate=0.03`, `depth=8`, `l2_leaf_reg=5.0`, `early_stopping_rounds=150`
- Валидация: GroupKFold по административным районам СПб (5 фолдов)
- Финальная модель обучается на всех данных, число итераций = медиана лучших по фолдам

### 5. Кластеризация застройки

PCA + KMeans → **11 кластеров городской среды**. Каждому автоматически присвоена стратегия базовой станции МТС:

| Кластер | Характеристики | Стратегия БС |
|---|---|---|
| Высотные башни 17+ эт. | медиана 51 м, площадь 129 м² | **Capacity** |
| Исторический центр | 3 эт., плотность 0.32 | **Capacity + Indoor** |
| Крупные жилые плиты 9+ эт. | 27 м, корпус 2 317 м² | **Capacity** |
| Советские дома 6–9 эт. | 20 м, корпус 1 790 м² | **Coverage + Capacity** |
| Хрущёвки и спальные районы | 3 эт., энтропия типов 0.70 | **Coverage + Capacity** |
| Сталинская застройка | 6 эт., контекст 23.2 м | **Coverage + Capacity** |
| Малоэтажная пригородная застройка | 2 эт., плотность 0.07 | **Coverage** |
| Малоэтажная периферия (ИЖС, гаражи) | 1–2 эт., плотность 0.04–0.14 | **Coverage 800 МГц** |
| Промзоны и склады | 1 эт., 86% пром. окружение | **Coverage** |

Итог: высота восстановлена для всех зданий города, застройка разбита на типы среды - каждый получил готовую стратегию для планирования сети.

```bash
pip install -r requirements.txt
```

### Полный пайплайн (очистка → матчинг → обучение → предсказание)

```bash
python pipeline.py src_A.csv src_B.csv ./output
```

Результаты в `./output/`:
- `final_buildings_with_addr_and_new_features.csv` - финальный датасет
- `rf_final_model.joblib` + `rf_final_model.json` - модель и метаданные
- `predictions/predictions_all_buildings.csv` - предсказанные высоты
